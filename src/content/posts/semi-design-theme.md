Semi Design 是字节跳动开源的设计系统，组件齐全、文档清楚。默认的视觉语言很「中后台」：蓝色主色、规整的圆角、信息密度高。

但个人博客不该长得像控制台。于是我保留了 Semi 的组件能力，把视觉层重新调了一遍。

## 先改 token，再改组件

Semi 的所有颜色都挂在 CSS 变量上。第一步是覆盖主色与背景：

```css
body {
  --semi-color-primary: #c14b2c;
  --semi-color-bg-0: #fffdf9;
  --semi-color-text-0: #201d19;
}
```

朱砂色做主色，纸白做背景，再用一套衬线字体负责标题。颜色和字体定下来之后，界面已经不像默认主题了。

## 深色模式

深色模式不是把颜色反过来，而是重新设计一套明度关系。背景要足够深，文字不能纯白，边框要几乎看不见但又能区分层级。

Semi 通过 `body[theme-mode="dark"]` 切换主题，所以只需要在根节点同步一个属性：

```ts
document.body.setAttribute('theme-mode', theme === 'dark' ? 'dark' : 'light');
```

博客正文和后台编辑器共用同一套变量，切换时不会出现一块亮一块暗的割裂感。

## 保留「组件感」，去掉「后台感」

- 用大字号衬线标题建立编辑感
- 用留白代替卡片分隔
- 标签做成细边框胶囊，而不是彩色块
- 交互反馈克制，只在 hover 时给出颜色变化

> 设计系统解决的是「一致」，不是「风格」。风格仍然需要自己做决定。

这也是我喜欢 Semi 的原因：它足够完整，又没有把审美锁死。
